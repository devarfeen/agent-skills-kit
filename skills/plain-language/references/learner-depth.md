# Learner depth

Extra teaching depth for one chat reply or the rest of the session, loaded when the user asks for more explanation ("explain like I'm new", "like I'm five").

Zero attribution: never add or leave co-author, AI, or tool attribution in any output.

- The normal reply already uses fifth-grade-level English, explains unfamiliar terms, and highlights glossary terms. Add one accurate everyday comparison for each technical term, once per term; keep the exact glossary term in bold alongside the comparison.
- Drop no fact, number, qualification, command, or identifier.
- It changes only what the user reads. Never apply it to the work, sub-agent prompts, or written artifacts, and never adopt a persona for it; a low-knowledge persona lowers accuracy.
- It ends when the user asks or the session ends.
