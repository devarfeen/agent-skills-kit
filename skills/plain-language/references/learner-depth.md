# Learner depth

Opt-in chat depth for one reply or the rest of the session, loaded when the user asks to be taught in very simple terms ("explain like I'm new", "like I'm five").

Zero attribution: never add or leave co-author, AI, or tool attribution in any output.

- Give the complete normal reply first, then one everyday comparison for each technical term, once per term.
- Drop no fact, number, qualification, command, or identifier.
- It changes only what the user reads. Never apply it to the work, sub-agent prompts, or written artifacts, and never adopt a persona for it; a low-knowledge persona lowers accuracy.
- It ends when the user asks or the session ends.
